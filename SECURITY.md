# Security

Please do not report a suspected update-signing key compromise in a public
issue. Email `security@cmux.com` with the affected version, platform, download
URL, and any observed hashes.

The expected update public-key fingerprint is:

```text
SHA-256 8feeefcadd6c55cfeb3dc3aeb52ca95649d914cc1430c9c798c9567374b6f657
```

Nightly release assets should be downloaded only from this repository or from
links on `https://cmux.com`. A valid manifest signature does not replace
macOS Developer ID/notarization or Windows Authenticode verification.
